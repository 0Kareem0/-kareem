## Overview

This is the personal portfolio and project showcase website of **Kareem** (`0Kareem0`). It combines old-web retro hacker aesthetics with modern frontend execution, sub-millisecond state updates, and dense information layouts.

### 🌟 Features

- **Retro Hacker Aesthetic**: Void dark palette (`#07080c`), monospace typography (`JetBrains Mono`, `Fira Code`), crisp 1px borders, CRT scanlines overlay, and Web Audio API synthesized tactile key clicks.
- **Interactive Command Terminal (`Ctrl+K`)**: CLI prompt supporting interactive commands (`help`, `whoami`, `ls`, `projects`, `cat about.txt`, `cat now.txt`, `cd <route>`, `socials`, `contact`, `clear`, `matrix`, `date`).
- **007 Project Case Studies**: Dedicated routes and technical case studies for all projects:
  - `001 / KAIJU` (`https://kaiju-phi.vercel.app/`)
  - `002 / Kitchen AI` (`https://kitchen-ai-seven.vercel.app/`)
  - `003 / Deceit` (`https://www.deceit.online/`)
  - `004 / Cyber-X` (`https://cyber-x-lilac.vercel.app/`)
  - `005 / Assembly Endgame` (`https://assembly-endgame-eta-eight.vercel.app/`)
  - `006 / Tenzies` (`https://tenzies-ten-green.vercel.app/`)
  - `007 / Clima` (`https://clima-virid-iota.vercel.app/`)
- **Status & Activity Log (`/now`)**: Public log of current priorities, reading lists, active build progress, and audio playlists.
- **Communication Dispatch (`/contact`)**: Terminal message transmitter (`$ sendmail --to kareem`) with direct links to official socials.

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS v3
- **Routing**: React Router DOM v6
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started Locally

```bash
# Clone repository
git clone https://github.com/0Kareem0/-kareem.git
cd -kareem

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
